Description

The Grade Calculator, written in python, is a simple program that calculates a student's final grade based on quiz, assignment, and exam scores. It uses weighted percentages to calculate the final grade and determines whether the student passed or failed.

Grade Weights

Quiz: 30%
Assignment: 30%
Exam: 40%

How to Run

1. Open Terminal.
2. Navigate to the project folder.
3. Run the following command: python3 grade_calculator.py
4. Enter the student’s name and the required grades when prompted.
5. View the calculated final grade and result.

## Example

If the quiz grade is 85, the assignment grade is 90,
and the exam grade is 80, the final grade is 84.50.
